# Theme and variations

The oldest game in music: state a tune simply, then show everything it can become. The listener's pleasure is
recognising it each time.

## How it moves

- **Section 1 states the theme plainly.** Point `motif.at` at it.
- **Every later section is a variation**, and no section replays another (the check refuses 60%+ overlap). Name in each
  section's function which transformation it is.
- **The required transformations**: inversion (upside down), augmentation (slower: 1.5× or more), diminution (faster).
  Use others too: transposition, fragmentation, octave displacement, retrograde.
- **Vary the accompaniment with the theme**: a variation is also a new texture, groove or harmony.

## Traps

- Variations that are just the theme with new drums.
- Losing the theme: every variation keeps something recognisable (its rhythm, its contour, its first interval).
