# False ending

A cadence, a held chord, silence: it sounds finished. Then it isn't. The return has to be worth the trick, so it comes
back changed and goes somewhere the first ending didn't.

## How it moves

- **Make the first ending convincing**: resolve the harmony, hold the last chord (a fermata: every part stops attacking
  for 2+ beats while it rings).
- **The stop** is its own section of 1-2 bars at intensity 0-1, after the peak so far and before the real end.
- **The return** is the motif varied and an octave higher (octave displacement): the piece has grown in the silence.
- **The real ending** is different from the false one.

## Traps

- A stop that's too short to believe (a beat is a breath, not an ending).
- A return that just repeats what came before.
