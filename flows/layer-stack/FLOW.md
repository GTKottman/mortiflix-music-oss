# Layer stack

Stems, not loops. Each loop is one or two parts of the same groove, written so any combination stacks: drums alone,
bass alone, the chords, the hook, a counter-line. The owner builds the track by choosing which layers play.

## How the loops relate

- **One or two parts per loop** (the check counts them).
- **Same length, same chart**: every layer fits every other layer at any point.
- **Each layer loops on its own** (an ostinato): it has to work when it's the only thing playing.
- Leave space: a layer that fills every register blocks the others.

## Traps

- Layers that only work all together: test each pairing in your head.
