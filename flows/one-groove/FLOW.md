# One groove, many turns

A producer's favourite kit: one beat that works, and everything else as options. Every loop keeps 75% or more of the
first loop's drums; the bass, chords and hook change from loop to loop.

## How the loops relate

- **Shared drums**: the same drum pattern in every loop (small fills are fine).
- **Turns**: each loop changes the harmony, the bass line or the hook (a variation of an earlier loop, 40-80% kept).

## Traps

- Changing the drums "for variety": the point is that they don't.
