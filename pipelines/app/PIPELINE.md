# App

Makes a full application for its owner, planned the way the industry makes software before any code is written.

The owner walks ten stages in order and OKs each one at its gate: Idea, Requirements, Screens, Look, Mockups,
Prototype, Tech plan, Tasks, Build, Ship. Nothing of a stage is made before the stage before it passed.

v1 (2026-10-21): the stages and gates only. Each stage's own work comes one version at a time
(Design Docs/App Studio - Plan v1.md).

v2 (2026-10-21): Idea. The chat asks the four questions (problem, who uses it, must do, must never do), each with a
suggested answer from the owner's idea; then one small call writes the one-page brief (`brief.md`). Both are quick
calls with no tools (src/quickidea.mjs), never a session. The other stages wait until their version is built.
